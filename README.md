# 🍿 Movie Hub

A dynamic, fully responsive movie discovery web application. Movie Hub allows users to explore trending movies and TV series, search for specific titles, and manage a personal wishlist. Built entirely with Vanilla JavaScript, it leverages the TMDB API to deliver a seamless, infinite-scrolling browsing experience with a premium, cinematic dark-mode UI.

## ✨ Features

* **Real-Time API Integration:** Fetches live data, including movie posters, ratings, and release years directly from The Movie Database (TMDB) API.
* **Smart Search:** Allows users to search for specific movies, dynamically switching between "Trending" and "Search" endpoints.
* **Infinite Scrolling:** Automatically fetches and appends the next page of movies as the user scrolls near the bottom of the page, ensuring a seamless browsing experience.
* **Cinematic & Responsive UI:** Designed with a mobile-first approach using CSS Grid and Flexbox. Features smooth hover animations, custom scrollbars, and a sleek dark-mode aesthetic.
* **Dynamic Wishlist:** Users can add or remove favorite movies to their personal wishlist (state management).
* **Interactive Navigation:** A fully responsive navigation bar that collapses into a smooth slide-out hamburger menu on smaller screens.

## 🛠️ Built With

* **HTML5:** Semantic markup and structure.
* **CSS3:** Advanced styling, CSS Grid, Flexbox, keyframe animations (`@keyframes`), and responsive media queries.
* **Vanilla JavaScript (ES6+):** Async/Await, Fetch API, DOM manipulation, event listeners, and state management without the use of heavy frameworks.
* **TMDB API:** External REST API used for fetching movie data and poster images.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
You will need a free API key from The Movie Database (TMDB).
1. Create an account at [TMDB](https://www.themoviedb.org/).
2. Navigate to your Account Settings > API.
3. Request an API key (Developer tier) and copy your **API Key (v3 auth)**.
