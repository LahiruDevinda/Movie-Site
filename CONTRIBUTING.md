# Contributing to Movie & TV Discovery 🎬

First off, thank you for considering contributing to this project! It is part of my **software engineering learning journey**, and I welcome feedback, bug reports, and pull requests that help improve the logic and user experience.

## How Can I Contribute?

### 1. Reporting Bugs 🐛
If you find a bug (like a broken image, a search error, or a UI glitch):
* Check the **Issues** tab to see if it has already been reported.
* If not, open a new issue and include:
    * A clear description of the problem.
    * Steps to reproduce the bug.
    * Screenshots if possible.

### 2. Suggesting Enhancements ✨
Have an idea to make the app better? (e.g., adding a "Genre" filter for TV shows or a "Dark Mode"). Open an issue with the tag `enhancement` and describe your idea!

### 3. Pull Requests (Code Changes) 💻
If you want to contribute code, please follow these steps:
1. **Fork** the repository.
2. Create a new **branch** (`git checkout -b feature/AmazingFeature`).
3. Make your changes (ensure your code follows the existing style).
4. **Commit** your changes (`git commit -m 'Add some AmazingFeature'`).
5. **Push** to the branch (`git push origin feature/AmazingFeature`).
6. Open a **Pull Request**.

## Coding Standards

To keep the project clean and maintainable, please ensure:
* **No hardcoded API Keys:** Never commit your `userData.js` with real credentials. Use `userData.example.js` as a template.
* **Meaningful Variable Names:** Use clear names (e.g., `isFetching` instead of `f`).
* **Comments:** Briefly explain complex logic, especially around API synchronization.
* **Formatting:** Use consistent indentation (2 or 4 spaces).

## Learning Goals
As this is a learning project, I am especially interested in PRs that focus on:
* **Refactoring:** Making the current JavaScript more efficient.
* **Performance:** Optimizing image loading or API calls.
* **Accessibility:** Improving the app for screen readers.
